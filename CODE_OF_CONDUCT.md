# Code of Conduct — Heros Todo

## Pledge

We pledge to make participation in Heros Todo a harassment-free experience for everyone — students, developers, researchers — regardless of age, background, identity, or experience level.

## Standards

- Be kind, precise, and technical. Critique ideas, never people.
- One logical change per issue/PR. No spam, no ads, no crypto pitches.
- Respect privacy: never post anyone's notes, file paths, or backup JSON in issues.
- Assume good intent; ask one clarifying question before disagreeing.

## Unacceptable

Harassment, insults, doxxing, sexualized language, trolling, or deliberately uploading malicious "demo" files.

## Enforcement

Report to the maintainer via <https://github.com/Ahmedbakr78> (prefix `[COC]`). First offense: warning. Repeated or severe: temporary or permanent ban from the repo. All reports stay confidential.

## Scope

Applies everywhere in this repository: issues, PRs, discussions, and any linked demo content.
