Install in 30 seconds

Chrome, Edge, Brave, Opera, Arc — any Chromium browser.

1. Download the release ZIP (or git clone https://github.com/Ahmedbakr78/Heros_Todo.git).
2. Open chrome://extensions (Edge: edge://extensions) and enable Developer mode.
3. Load unpacked → select Heros_Todo/todo-panel-extension/.
4. Pin Heros Todo, click the icon — the panel opens. Choose a folder or Load demo.

Updating? Press Reload ↻ on the extension card — Hub must read v2.2.0.

Questions

Full 20-question list in the README.

Is it really free?

Yes — MIT licensed, unlimited everything, no accounts.

Where do my files go?

Nowhere. They stay on your disk; the app holds only permission handles and your marks/tasks locally.

“Could not read folder: NotFoundError”?

The saved folder link died — open Spaces and press ↻ on that workspace to re-pick it.

Checkboxes don't click?

Reload the extension card — you run an old copy. Since v2.1 every box toggles the real line.

How do I move machines?

Hub → Backup → copy the JSON → Restore. Re-pick folder workspaces once.
